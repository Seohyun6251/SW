# SW 자동학습 스케줄링 시스템

## 프로젝트 소개 
사용자의 시험 일정, 과목별 중요도와 학습 필요도, 
공부 가능 시간을 바탕으로 개인별 학습 시간표를 생성하는 웹 프로젝트

## 프로젝트 목표
- 학습 우선순위와 과목별 학습시간 자동 계산

- 사용자의 공부 가능 시간에 맞춘 학습 시간표 생성

- 학습 결과를 반영한 학습 일정 재조정

- 데이터베이스를 활용한 웹 서비스 개발

## 개발 환경

- OS: Windows 11
- IDE: Visual Studio Code
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js
- Database: MySQL
- Database Tool: MySQL Workbench 8.0

## 개발 계획

- Plan B: 전체 학습 가능 시간에 맞춰 과목별 학습시간 계산 및 제공

- Plan A: 과목별 학습시간을 실제 공부 가능 시간대에 배치하여 시간표 생성

- +α: 웹 서비스를 모바일 앱으로 확장하고 실제 배포 진행
